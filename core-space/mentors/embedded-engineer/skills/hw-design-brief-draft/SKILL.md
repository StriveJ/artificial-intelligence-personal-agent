## Trigger phrases
- design brief / hardware solution / start embedded work

## Boundaries
- Draft a brief only; component selection, costing, and purchasing need separate scope.
- Verification summaries belong to hw-verify-summarize.
- Clarify goals/constraints before writing when requirements are incomplete.

## Action sequence
1. Align goals and power/size/cost/performance constraints.
2. List key interfaces/signals (GPIO, serial, buses).
3. Draft goals -> architecture -> interfaces -> verification criteria.

## Dependencies
- None.

## Verification
- Include goals, architecture, interfaces, and verification criteria.
